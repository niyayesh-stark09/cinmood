معرفی پروژه سینمود بخش وب1 (لندینگ سینمود)

سینمود (CinMood) یک وب‌سایت با هدف کمک به کاربران برای پیدا کردن فیلمی متناسب با حال‌وهوای آن‌هاست.

ایده‌ی اصلی پروژه، ترکیب دنیای سینما با هوش مصنوعی است تا تجربه‌ی انتخاب فیلم ساده‌تر و جذاب‌تر شود.


👩‍💻 توسعه‌دهنده

[نیایش کرم پور]

✨ قابلیت‌ها

- معرفی ایده و هدف پروژه
- نمایش مراحل کار سینمود
- نمایش کارت‌های فیلم‌های محبوب به همراه پوستر و توضیحات
- طراحی دکمه‌های هدایت کاربر به صفحات دیگر
- طراحی رابط کاربری با تمرکز بر سادگی و زیبایی بصری


🛠️ ابزارهای استفاده‌شده

- HTML5 برای ساختار صفحات
- CSS3 برای طراحی و استایل‌دهی
- Visual Studio Code برای نوشتن و ویرایش کدها

📁 ساختار پروژه

- "index.html" — صفحه‌ی اصلی وب‌سایت
- "start.html" — صفحه‌ی شروع تجربه‌ی سینمود، در صورت ایجاد
- "mood.html" — صفحه‌ی مربوط به تشخیص مود، در صورت ایجاد
- "style.css" — استایل‌های صفحات
- "images/" — پوشه‌ی تصاویر و پوسترهای پروژه
- "fonts/" — پوشه‌ی فونت‌ها



^^امتیاز های اضافه ی انجام شده^^

**2  سکشن (فیلم های محبوب) با کارت

**3 فرم (وقتی آماده شد خبرم کن)
